# UJASCODE Factory 3D Experience

Responsive Three.js website built from the supplied factory source asset.

Model:
- models/20251228_004_RC_LOD0.obj
- models/20251228_004_RC_LOD0.mtl

The original factory texture supplied in the archive is retained in `models/`.

## Features
- Desktop + phone optimized
- Touch rotation / pan / zoom
- Responsive camera framing
- Slow automatic orbit after inactivity
- Reset View
- Information panel
- Premium UJASCODE industrial UI
- Three.js OBJ + MTL loading

## Run
Use VS Code Live Server, or:

```bash
python -m http.server 5500
```

Then open `http://127.0.0.1:5500/`.

Do not use `file://`.

## Asset
The model and texture files were supplied in the user's archive. Verify the source license and attribution requirements before commercial/public deployment.
